# expense tracker

simple expense tracking app made with html css and javascript. data is saved in localstorage so nothing is lost when you close the browser.

## how to run

just open index.html in a browser. thats it, no setup needed.

## features

- add, edit, delete expenses
- filter by category, month, year
- monthly summary with charts (chart.js)
- categories: food, transport, entertainment, health, education, shopping, bills, other

## tech

html + css + javascript (vanilla), localstorage for data, chart.js via cdn
